# Airbnb Data Analysis Dashboard (Tableau)

## Project Overview
This project presents an interactive Tableau dashboard built to analyze Airbnb listing data.  
The analysis focuses on pricing, availability, room types, and neighbourhood-level trends to generate actionable insights.

## Tools Used
- Tableau
- Data Analysis
- Data Visualization
- Data Cleaning

## Key Highlights
- Built interactive dashboards with filters for dynamic analysis  
- Analyzed pricing and availability patterns across locations  
- Identified trends to support data-driven decision making
